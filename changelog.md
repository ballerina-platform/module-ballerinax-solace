# Change Log

This file contains all the notable changes done to the Ballerina Solace package through the releases.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.0] - 2026-11-27

### Fixed

- [Fix a `solace:Listener` service in `AUTO_ACK` mode losing every guaranteed message whose `onMessage` returns an error or panics, because the message was acknowledged before `onMessage` ran; the message is now acknowledged after `onMessage` returns successfully, settled as failed and redelivered (up to the queue's maximum redelivery count) when `onMessage` returns an error or panics, and rejected when it cannot be converted or bound to the `onMessage` parameter type](https://github.com/ballerina-platform/ballerina-library/issues/9834)
- [Fix a message sent with an empty `userData` array never being accepted by the broker, which made `sendAwaitAcknowledgement` time out and blocked later guaranteed sends on the same producer; an empty `userData` is now sent as if the field were absent](https://github.com/ballerina-platform/ballerina-library/issues/9865)
- [Fix the `senderTimestamp`, `receiveTimestamp` and `sequenceNumber` of a received message being truncated to 32 bits, which made every epoch-millisecond timestamp and any sequence number above 2^31-1 wrong, for both `MessageConsumer` and `Listener`](https://github.com/ballerina-platform/ballerina-library/issues/9844)
- [Fix a `messageSelector` on a direct topic subscription being silently ignored; a `MessageConsumer` or `Listener` service with one now fails to initialize or attach with an error, since selectors are supported only on durable topic endpoints and queues](https://github.com/ballerina-platform/ballerina-library/issues/9849)
- [Fix `secureSocket.trustedCommonNames` being ignored, so a broker certificate whose common name was not in the list was accepted; a connection now fails when the certificate's common name is not in a non-empty list](https://github.com/ballerina-platform/ballerina-library/issues/9861)
- [Fix direct topic `MessageConsumer`s and `Listener` services silently stopping receiving after the session reconnects, because the topic subscriptions were not re-applied, and `gracefulStop` then failing with `400: Subscription Not Found`; a subscription the broker refuses when re-applying it is now logged as a warning](https://github.com/ballerina-platform/ballerina-library/issues/9863)
- [Fix `gracefulStop` interrupting an `onMessage` that runs longer than 5 seconds, which left its work half done and failed its settlement; `gracefulStop` and `detach` now stop delivery to every service and wait, without a time limit, for the in-flight `onMessage` and its settlement before closing resources](https://github.com/ballerina-platform/ballerina-library/issues/9845)
- [Fix `immediateStop` waiting up to 5 seconds for each attached service; it now returns without waiting for, or interrupting, the in-flight `onMessage`](https://github.com/ballerina-platform/ballerina-library/issues/9846)
- [Fix a `MessageConsumer` in `CLIENT_ACK` mode leaving a message that cannot be converted or bound to the requested type unsettled until the consumer closes, so it was never redelivered, never counted toward the redelivery limit and held a slot of the flow's unacknowledged-message window; on a non-transacted queue or durable topic endpoint the message is now rejected, so it moves to the queue's dead message queue if the broker's DMQ configuration routes it there and is discarded otherwise](https://github.com/ballerina-platform/ballerina-library/issues/9848)
- [Fix the client calls that wait for the broker, such as `receive`, `send`, `sendAwaitAcknowledgement`, `commit` and `close`, blocking every other non-isolated strand for the whole wait, which could hang a program that closed a consumer while another strand waited in `receive`](https://github.com/ballerina-platform/ballerina-library/issues/9864)
- [Fix a `solace:Listener` service in `CLIENT_ACK` mode leaving a message that cannot be converted or bound to the `onMessage` parameter type unsettled until the session closes, so it was never redelivered, never counted toward the redelivery limit and held a slot of the flow's unacknowledged-message window; on a non-transacted queue or durable topic endpoint the message is now rejected, so it moves to the queue's dead message queue if the broker's DMQ configuration routes it there and is discarded otherwise](https://github.com/ballerina-platform/ballerina-library/issues/9847)

### Changed

- [Make `caller->ack()` and `caller->nack()` log a warning and do nothing in an `AUTO_ACK` service, since the listener settles the message itself after `onMessage` returns](https://github.com/ballerina-platform/ballerina-library/issues/9834)
- [Log a warning when `secureSocket.keyStore` is set, and document that the key store is not used and the `auth` configuration authenticates, since client certificate authentication is not supported yet](https://github.com/ballerina-platform/ballerina-library/issues/9862)
- [Reject a `trustedCommonNames` entry that is empty, contains a comma, or has leading or trailing whitespace, since such a name can never match a certificate's common name](https://github.com/ballerina-platform/ballerina-library/issues/9861)
- [Leave the messages received but not yet passed to `onMessage` on a non-transacted queue or durable topic endpoint for the broker to redeliver when a listener stops, and process them before a graceful stop on a direct topic or a transacted listener, where they would otherwise be lost or already committed](https://github.com/ballerina-platform/ballerina-library/issues/9845)
- [Make a second `gracefulStop` wait for the first one to release the listener's resources, and make an `immediateStop` called while a `gracefulStop` or `detach` is waiting on `onMessage` release the resources at once instead of waiting](https://github.com/ballerina-platform/ballerina-library/issues/9845)
- [Reject a message that a `MessageConsumer` in `CLIENT_ACK` mode cannot convert or bind, on a non-transacted queue or durable topic endpoint, instead of returning it to the queue when the consumer closes; a deployment with a wrong payload type now sends the messages it receives to the queue's dead message queue, or discards them when the broker's DMQ configuration does not route them there](https://github.com/ballerina-platform/ballerina-library/issues/9848)
- [Propagate the cancellation of a strand that is waiting in a client call as a panic, raised once the broker call returns, instead of returning it as an `Error`; a message that a cancelled `receive` of a non-transacted `CLIENT_ACK` consumer had already taken is returned to the queue for redelivery; make `close` of a `MessageProducer` or `MessageConsumer` return without repeating the cleanup when it is already closed, return a `Consumer is closed` error from a `receive` that ends because the consumer was closed by another strand, and run the `send`, `receive`, `commit` and `rollback` calls of a transacted `MessageProducer`, `MessageConsumer` or listener one at a time, since the Solace API requires serial access to a transacted session](https://github.com/ballerina-platform/ballerina-library/issues/9864)
- [Reject a message that a `solace:Listener` service in `CLIENT_ACK` mode cannot convert or bind, on a non-transacted queue or durable topic endpoint, instead of returning it to the queue when the listener stops or the service is detached; a deployment with a wrong payload type now sends the messages it receives to the queue's dead message queue, or discards them when the broker's DMQ configuration does not route them there; a message that cannot be converted and is still queued behind the in-flight `onMessage` when the listener stops, in either ack mode, is now left for the broker to redeliver without calling `onError`, like the other queued messages](https://github.com/ballerina-platform/ballerina-library/issues/9847)
